# Quick Start - Message Deletion Manager

## How to Delete a Message

1. Right-click on **your own message**
2. Select **"Delete my message"**
3. Wait for admin approval
4. You'll get a DM with the result

## Channel Requirement

**The MAF Admin user must be in the channel** for deletions to work:
- For public channels: Invite MAF Admin if not already present
- For private channels: Add MAF Admin to the channel

**Privacy notice:** When added to a private channel, the Message Deletion Manager bot can see all data in that channel.

## What You Can Delete

- Accidentally shared personal information (phone numbers, addresses, etc.)
- Incorrect or outdated information
- Messages sent to the wrong channel
- Genuine mistakes

## What You Cannot Delete

- Other people's messages (only your own)
- Messages to avoid accountability
- Inflammatory comments after the fact
- Historical conversations to revise the past

## Important Notes

- **Admin approval required** - An administrator reviews every request
- **Everything is logged** - All deletions are permanently recorded in our audit system
- **Response time varies** - Most requests reviewed during business hours
- **For urgent issues** - Contact an admin directly if you've leaked credentials or security info
